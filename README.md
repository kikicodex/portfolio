# Keerthana K R — Portfolio

Personal portfolio website for **Keerthana K R**, Full-Stack Engineer & AppSec Enthusiast based in Bangalore, India.

**Live:** [keerthana-portfolio.vercel.app](https://keerthana-portfolio.vercel.app) *(update once deployed)*

## Stack

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Toasts:** Sonner
- **Language:** TypeScript

## Sections

- Hero — staggered headline, animated SVG avatar, particle canvas
- About — animated stat counters
- Projects — Kernel, EngineerEase, Healthcare Data Tool (3D tilt cards)
- Skills — 7 categories with hover-glow pill tags
- Experience & Education — vertical timeline
- Contact — copy-to-clipboard email

## Local dev

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
